# Work Operating System

This project develops a repeatable way to plan, delegate, execute, and review digital work for Calgary Public Library. Anyone working on the project, including collaborators and AI agents with authorized access, can use this folder to find the current plans, decisions, graphs, and handoffs.

## Start here

Use the [work levels and forks map](https://drive.google.com/file/d/1LXN-J06fdXyfqcvd5G8GfLRFdb14lRSg/view?usp=drivesdk) to classify an incoming assignment, identify the disciplines it needs, and decide which paths should run independently.

Use the [media roles and Calgary Public Library practice guide](https://drive.google.com/file/d/1g3ZTgnYt_iyAS1sUheMh8rEbOUeknGK4/view?usp=drivesdk) to identify which discipline, level of responsibility, and professional judgment an assignment needs.

1. Open the [graph catalog](https://drive.google.com/file/d/1hgyCFe4cNib77_GtV-8lYVXuELJTwfdV/view?usp=drivesdk) to choose the view that answers your question. It includes the seven graph types and editable Mermaid examples.
2. Open the [Monday planning board](https://www.figma.com/board/7LOb9fzEM6BzYY9eoBCgjW) for the worked example. It shows planned tasks, prerequisites, owners, and what Tuesday needs to receive.
3. When running a plan, check your assigned role, access to the linked inputs, and who receives the result. Use the plan's source links and stable task IDs. Record what was actually opened, attempted, returned, and accepted. Link the exact output version to the next assignment or decision. Keep Asana read-only.
